Scenarios adalah Shallow Module
SHALLOW
src/scenarios.js:87-106
applyScenario() hanya melakukan Object.assign() dan logging. Interface complexity ≈ implementation complexity. Tidak ada enkapsulasi atau validasi.
// Current: 1:1 mapping dengan implementasi export function applyScenario(state, scenarioKey) { const scenario = SCENARIOS[scenarioKey]; Object.assign(state, scenario.initial); // trivial state.simTime = 0; ... }
Deletion Test: Jika dihapus, caller bisa langsung pakai Object.assign(state, SCENARIOS[key].initial) — sama saja.
main.js Mengandung Logic di Orchestrator
FRICTION
src/main.js:79-144
Fungsi simulate() berisi logic RLR scaling, governor integration, dan history management. Orchestrator seharusnya hanya mengkoordinasi, bukan mengimplementasi logic.
// Problem: Logic tercampur dengan orchestration function simulate(dt) { if (!state.running) return; // RLR logic di orchestrator? if (state.rlrEnabled) { state.rlrTime += dt / 3600; const load = getRLRLoad(state.rlrTime * CONSTANTS.SPEED); currentPref = load; } // History management di sini juga... history.delta.push({ t: state.simTime, v: state.delta }); }
Impact: Sulit di-test secara isolated, tanggung jawab tidak jelas, dan membuat main.js membesar.

DEEP ✓
src/physics/swing.js:11-66
Interface sederhana (rk4Step(state, params, dt)) tapi implementasi kompleks (RK4 integration dengan 4 stage evaluation). Enkapsulasi numerical complexity dengan baik.
// Simple interface... export function rk4Step(state, params, dt); // ...hides complex implementation: const k1 = ode(state, params); const k2 = ode(state2, params); const k3 = ode(state3, params); const k4 = ode(state4, params); return weightedAverage(k1, k2, k3, k4);

State Mutation Tidak Terkontrol
FRICTION
src/state.js:64-72 + src/main.js:114-119
Meskipun ada setDelta(), setPm(), dll., main.js langsung mutate state: state.delta = newState.delta. Inconsistent mutation pattern.
// state.js exports setters... export function setDelta(v) { state.delta = v; commit(); } // ...but main.js bypasses them: state.delta = newState.delta; // direct mutation! state.omega = newState.omega; state.Pm = governorState.y;
Impact: Double standard, commit() tidak dipanggil, event bus tidak konsisten. Debugging sulit.

Recommendations

🔴 High Priority: Extract Simulation Logic from main.js

Buat modul baru src/simulation.js yang menangani:

  • RLR time scaling dan load lookup
  • History management (append, prune)
  • Simulation step orchestration (governor → swing → stability)

Benefit: main.js menjadi pure orchestrator (event loop + rendering), simulation logic isolated dan testable.

🟡 Medium Priority: Consistent State Mutation Pattern

Pilih salah satu:

  1. Option A: Hapus setters, allow direct mutation, hapus event bus (simpler)
  2. Option B: Enforce setters everywhere, buat main.js pakai setters (consistent)

Recommendation: Option A lebih cocok untuk proyek ini — event bus tidak terlalu berguna karena render sudah di-trigger per-frame.

🟢 Low Priority: Replace panels.js with Native HTML

Ganti toggle buttons dengan <details> element:

<details open> <summary>▼ Diagram Phasor</summary> <svg>...</svg> </details>

Benefit: -45 lines JS, native browser behavior, accessible by default.
